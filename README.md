# Niger Delta Water Quality (ND Water Quality)

An offline-capable water quality assessment and groundwater vulnerability application designed to support environmental monitoring and research in the Niger Delta region of Nigeria.

## Main Features
- Water quality data entry and management.
- Water Quality Index (WQI) assessment.
- Groundwater vulnerability assessment using DRASTIC methods.
- Geographical mapping of sampling locations.
- Data import and export.
- Water quality reports.
- Local data storage for offline use.

## Technology
- React
- Vite
- JavaScript
- Capacitor
- Electron

## Project Purpose
To support groundwater quality monitoring, environmental research and water resource management.

## Important Note
Scientific outputs should be interpreted alongside laboratory results, applicable Nigerian standards and WHO guidelines. This application is a research-support tool and does not replace accredited laboratory testing.
